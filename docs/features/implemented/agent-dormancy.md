# ペインの休止

**休止中・会話は再開できる (プロセスは終了している)**。休止は、会話を残して Claude / Codex のプロセスを終了する操作です。再開すると既存のエージェント別操作で会話を続けます。終了したプロセスの途中の実行状態を復活させる操作ではありません。

表示中のペイン、作業中、権限待ち、質問待ち、エラー・枠切れ・種類の分からない通知、プロセスの状態が不明なもの、会話の再開先が不明なものは保護します。別の窓や区画にあるペインも全体の席数に含めます。画面が非表示というだけでは休止しません。

## 時間と圧による候補

通常は以前と同じ時間制です。意味のある出力や入力、プロセス状態の変化がなく、既定 60 分が過ぎた対象は、状態を再確認して休止します。時刻だけが変わる既知の状態表示や同じ画面の描き直しは、仕事の再開と数えません。端末の表示キャッシュが残る対象はキャッシュを退避し、その時点ではプロセスを終了しません。

空きメモリが圧の閾値以下、または全ペイン数が閾値以上になると、より短い待機時間で候補を提示します。強い圧でも作業中・権限待ち・質問待ちを保護し、**人の確認までプロセスを終了しません**。通常の 60 分を超えていても、圧のある間は確認が必要です。

候補は通知の「候補を確認」または [ペイン掃除](tab-sweep.md) で開き、名前・待機時間・圧の段階を見て「確認して休止」を押します。確認後に活動や会話、プロセス状態が変わった対象は残します。確認はその対象に限り、1 分で失効します。

空きメモリを取得できない環境や計測の失敗・不正な値では、席数が多くても時間制のみへ落とします。設定画面には取得不能の理由を表示します。取得できるときは現在の MiB を表示します。計測には既存のシステム計測を使います。

走査は既存の 10 分間隔です。15 分・5 分の閾値に達した直後とは限らず、次の走査で候補になります。選んだ通常時間が圧の待機時間より短い場合は、その短い時間を使います。0 分は圧を含めた自動休止全体を停止します。

## 完了の未読と会話の記録

未読が完了だけなら、会話の記録を保存できたことを確認してから休止できます。記録がない、空、不完全、最後の指示への返答がない、保存に失敗した、保存中に会話やプロセスが変わった場合は終了しません。完了以外の未読や未解決の権限・質問・注意は引き続き保護します。

終了前に完了通知と保存した記録の対応も端末内に保存します。この保存に失敗した場合もプロセスを残します。休止するだけでは既読にせず、プロセス終了の更新やアプリ再起動後も未読の完了を保持します。

完了のある休止中のペインを押すと、ダッシュボードの会話面で保存した記録を開きます。この閲覧ではプロセスを起動せず、通知も自動で既読にしません。会話面の「会話を再開」は既存の元画面へ移る操作を使います。明示した完了扱いや、再開後の通常の既読操作は既存の動作に従います。会話列がすべて固定されて開けない場合は通知で知らせ、プロセスの起動に流しません。

保存した会話はアプリの記録領域に置き、会話面では既存の読み取り上限内の末尾を表示します。新しい実行や新しい権限・質問の通知を、古い完了で覆いません。

## 設定名・既定値・戻し方

設定 → 自動化で変更できます。圧の数値は正の整数に正規化し、強い圧の空きメモリと待機時間は通常の圧以下、席数は通常の圧以上に揃えます。

| 対象 / 設定名 | 既定値 | 以前 → 現在 | 戻し方 |
|---|---|---|---|
| R-05 `autoSweepCloseWithoutConfirmation` | `false` | 判定後すぐ終了 → 候補を確認してから終了 | 「AI判定後、確認せずにペインを閉じる」をオン |
| M-04 `dormancyPressureSettings.enabled` | `true` | 時間制のみ → 通常は時間制、圧があるときは候補提示 | 「メモリ圧と席数に応じて休止候補を提示する」をオフ |
| `dormancyPressureSettings.memoryPressureMiB` / `severeMemoryMiB` | 2048 / 1024 MiB | 空きメモリがこの値以下で圧 / 強い圧 | 数値を調整、または段階制をオフ |
| `dormancyPressureSettings.panePressureCount` / `severePaneCount` | 40 / 60 ペイン | 全席数がこの値以上で圧 / 強い圧 | 数値を調整、または段階制をオフ |
| `dormancyPressureSettings.pressureIdleMinutes` / `severeIdleMinutes` | 15 / 5 分 | 圧 / 強い圧で候補になる待機時間 | 数値を調整、または段階制をオフ |
| M-05 `dormancyAllowUnreadCompletion` | `true` | すべての未読を保護 → 完了だけなら保存後に未読を残して休止可 | 「完了通知だけが未読のペインは、会話の記録を保存してから休止する」をオフ |
| 通常時間 `mycmux:agent-dormant-minutes` (localStorage) | 60 分 | 既存の時間制を維持 | 時間を選択。0 分は自動休止全体を停止 |

2048 / 1024 MiB と 40 / 60 ペインは、作者の空き 1〜3 GB・30〜60 席を踏まえた初期値です。中間で早めに候補を見せ、下限付近ではさらに早く知らせます。15 / 5 分は候補を見せる猶予で、作業中を終了する期限ではありません。閾値の設計判断は [休止の設計](../../design/agent-dormancy.md) に記録しています。
