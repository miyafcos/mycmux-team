構造を理解しやすい階層**にしたい」

## 翻訳原則 (配置図 = LayoutMinimapPanel / タブ再配置プレビュー共通)

1. **位置の地図に「関係の階層」を重ねる**: WS>ペイン>タブの空間配置に加え、
   spawn 系譜 (`tab.origin.parentTabId`) で 母艦 → ↳作業者 の親子を視覚化する
   (インデント・接続線・同色系グルーピングのいずれか)。案件のまとまりが構造で読める
2. **生きている = 稼働の流れが見える**: agentStatus=working のタブは接続線 or チップに
   微アニメーション (流れ/呼吸)。idle は静止。完了・エラーは ✓/✗ 系の解決マークで静まる。
   「動いてるものだけが動く」— 全体が常時ちらつく演出は禁止
3. **チップに最小の生体情報**: エージェント種別・状態・最終出力からの経過 (既存
   formatLastOutputAgeCompact)。数字はカウントアップ演出でなく静かな更新
4. **視認性が最優先**: 色は意味のみ (working/idle/done/error)・テーマトークン準拠・
   prefers-reduced-motion で全アニメ停止・日本語9px床
5. (後便候補) フォロー: 「今いちばん動いている場所」へのジャンプ導線

## 適用先

- 即時: タブ再配置レーン Gate 3 のプレビュー描画 (グループ=関係の束として描く。
  母艦/作業者 role を pane role (mother/worker) と系譜から視覚化)
- 後便: LayoutMinimapPanel 本体の生体化 (独立レーン。上記1〜4を実装)

## 注意 (既存FBとの整合)

一方向の掲示物にしない — 配置図はクリックで飛べる操作面であり続けること
(feedback_no_oneway_snapshot_ui)。アニメーションは情報 (稼働状態) の表現に限定し装飾にしない。
