# 機能ごとの制限

## 花火とテーマ

花火は「設定 → 外観 → すべてのテーマを表示」の「個性の強い暗色」から選べます。設定を開いている間は端末面の景色が暗くなり、閉じると元の明るさに戻ります。テーマを変更したときは、開いているほかの窓は従前のテーマのまま表示します。別の窓が次に起動するとき、保存済みのテーマと背景を読みます。

merge の花火は端末に表示された成功行を手がかりにします。確認には Git の履歴やホスティングサービスの結果を使ってください。

- 同じタブで同じ成功行が続く場合、2 回目以降は画面の再描画と同じ扱いになります。成功行の引用にも花火が上がることがあります。
- 出力が 1 行の途中で途切れたときに、窓のサイズや表示場所を変えると、その行の花火が 1 回増えたり、上がらなかったりすることがあります。
- 端末の再起動直後や、出力を取りこぼして再同期したあとの再描画でも、まれに花火が 1 回増えることがあります。
- コミット範囲のない Fast-forward の直後は、最初の範囲付きの成功行を同じ成功の補足として扱います。

## Windows のパス

エクスプローラーで開くには、Windows のファイル名として有効な既存のパスを使ってください。ファイル名に二重引用符は使えません。管理者権限の mycmux と通常権限のエクスプローラーでは、割り当てたドライブが片方からだけ見えることがあります。同じ権限で開くか、アクセスできる共有の UNC パスを指定してください。Web タブの mzopen には、通常のドライブまたは UNC 表記を使ってください。

## 起動メニューと参考額

- Codex のモデル候補は既定ホームのキャッシュに従います。候補の読み込みが終わると固定候補からキャッシュの候補へ表示が切り替わります。モデル名を見てから選択してください。上下に分割して起動と取消のボタンが見えないときは、タブの表示場所を広げてください。
- 一覧と参考単価は 2026 年 11 月 18 日に確認したカタログに基づきます。GPT-6.2 はキャッシュ書き込みの保持時間がログに無いため、30 分の単価で見積もります。Gemini 4 Carbon は 2026 年 12 月 1 日からの通常単価を使うため、11 月 30 日までの導入期間の参考額は実額より高くなります。
- 単価と系列は、会話を初めて取り込むか追記を取り込むときに計算します。更新前に取り込んだ会話は、追記が入るまで保存済みの参考額や系列を表示することがあります。
- Gemini 4 Carbon の low・medium・high、Gemini 4 Hydrogen の low・medium・high・xhigh、Gemini Pro Orchestrator と Argon は未確認の単価として扱います。実額は提供元の請求を確認してください。

## 会話と配置図

- 会話の検索中に記録そのものが置き換わった場合は、その時点で検索を止めます。画面に「会話の記録が変わったため、途中で止まりました」と出たら、最新の記録を読み込んでから「もう一度検索」を押してください。
- 作業中の Claude Code への入力は、キューに追加した段階では到着が確定しません。以前の送信の結果がまだ分からない状態で同じ文を続けて送ると、会話記録の本文だけではどちらが届いたかを区別できないことがあります。端末または会話を確認してから次の操作を行ってください。
- 配置図の幅が狭く、画面の文字サイズを大きくしている場合は、ラベルの一部が収まらないことがあります。タブ名は各タブの見出しや一覧でも確認できます。
- 日本語の Windows で Claude Code の Bash ツールがすでに文字化けした出力を記録した場合、端末と会話の表示にはその記録が出ます。Claude Code を実行する環境で UTF-8 出力を設定し、CLI の既存の起動設定やコマンドの表示言語と両立することを確認してください。

## 更新

Windows では更新のインストーラーがアプリの終了を進めます。通常の終了操作と同じ片づけをすべて実行できる保証はありません。実行中のコマンドや未送信の入力がある場合は、更新を始める前に作業を区切ってください。
