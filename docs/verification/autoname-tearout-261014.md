# サイドバーの名前と切り離しの掴み点の修正

対象枝: fix/autoname-tearout-0882-261014。起点: 3a60dce46b040e9adba0ec735433a18f0a75c120。作業開始時点に v0.88.1 のタグが無かったため、指定された配信枝の先端を固定しました。配信枝・本番アプリ・版番号の変更はこの修正の範囲に含みません。

名前は会話の題名を優先します。規則で取れた具体名が返事・続き・履歴不足・読み取り失敗で取れなくなったときは、同じ所有者の直前の名前を保持し、「前回」と理由を出します。仮定: 保持は同じ実行中の最後の確認から 30 分です（古い作業を永久に現在の作業と見せないため）。新しい具体的な指示、明示された中止・置き換え、所有者の変更で保持を解除します。起動時のラベルが現在も使える場合は、席のラベルとして扱います。保存名だけを会話の根拠にする処理は加えていません。

U1〜U10 の理由は実行時の意味情報に載せ、サイドバーのツールチップとワークスペースの説明に出します。「作業内容未取得」同士の識別番号は付けません。手で付けた名前・従来の読みやすい名前の保護を継続します。診断ログは本文・題名・パスを含めず、タブ ID・理由のコード・前回名を保持したか・観測回数を記録します。同じ理由は 5 分ごとに回数をまとめます。

Codex の記録は既存の会話 ID を使い、ID が無い場合は現在の PTY の確認済みの対応、または観測された起動時刻と cwd で一意に絞ります。別席が持つ記録、子エージェント・exec の記録、同じ cwd の競合した起動を候補にしません。時刻の窓は前後 30 秒、探す日付は前後 1 日、探索は深さ 3・最大 2048 エントリです。一意に決まらない場合は、起動ラベルで席を識別します。読めた会話の最初の依頼と spec の見出し・ファイル名も命名材料になります。

Windows は start_dragging の直前に現在のカーソルから掴み点を引いて置き直します。換算はカーソルの画面の倍率を使い、境界で HWND の倍率が違えば、その割当倍率でも位置を補正します。reveal と開始時で同じ位置計算を使います。Mac は original_down を受け取った後、開始の基準フレームを取る前に origin_under_pointer で置き直します。

新しいログ欄 start_alignment は補正前後の誤差を残します。既存の cursor_window_lag_px は補正後の基準に合わせて継続します。再掴み・dock の動作、PTY の受け渡し順序、窓のサイズの扱いは維持しています。

旧試験の「返事の後は未取得へ落とす」「未取得同士は番号で区別する」の期待値を今回の裁定に合わせています。前回名を許す検査では具体的な旧名との一致と fresh=false・staleSince・理由を確認し、新しい名前の確定や否定・所有者の境界の検査は継続します。読み取り間隔が違う試験では、以前に確認できた名前が違う場合があるため、前回名を保持した最終表示の一致は要求しません。

名前の候補が衝突して実際には未取得表示になった場合は、その候補を保持の根拠にしません。「作業内容未取得」に「前回」が付く状態を防ぐ試験を加えています。
