# エージェント設計・段 B2 の書き出し

6番目の面「書き出し」とキー6。履歴の便B1を取り込むまで5番目は無効。サービス・層・許された本文を選び、外したものと名前検査を確認して、保存先を選ぶ。本文は既定で全部外す。指示の文書は見出しごとに選ぶ（次の見出しまでの断片）。

Rust は既存の目録と許された文書だけから1冊のHTMLを組む。設定・会話の再走査はしない。記憶の索引・本文・量・置き場所、秘密、会話本文・ログ、根拠の本文は共有しない。付録では選ばなかった見出しを外し、秘密の代入や鍵の場所を含む行も外す。出力はホーム相対・明るい背景・外部資源なし・スマホ幅対応。製品版は実際のコンパイル版を出す。

ホームの表記を ~ に置き換え、完成したHTMLの全体・復号した本文と属性を NFKC とUnicodeの大文字小文字をそろえて検査する。Unicode15の表はPython標準ライブラリで生成し、新しい依存は足していない。OSの利用者名・メール・電話と、~/.mycmux/agent_design/export-names.txt（1行1語・空行と#コメントは無視）を使う。1件でも当たれば保存しない。語とHTMLの行はローカル画面だけで表示する。

保存は目録と一覧を再確認し、確認時のHTMLのハッシュと一致したときだけ行う。本文・一覧はログに出さない。既存ファイルを上書きせず、新しいHTML名で原子的に保存する。利用者の設定フォルダと非公開の場所、シンボリックリンク経由には保存しない。一覧だけは指定された利用者側の場所で編集できる。

試験は新しいRust・Vitest、合成ホームの3種類の目印、既存4面の登録、テーマと文字の品質、公開検査、実PC目録の2冊とネットなしのブラウザ写真。実IPCとWindowsのビルドはこの便で行わない。
