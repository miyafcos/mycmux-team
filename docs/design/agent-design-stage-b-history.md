# エージェント設計の履歴（段 B1）

読者＝母艦・PC の実装者／語り手＝この便の席。

5 つ目の「履歴」は、サービスと作業フォルダの列を保ち、日別の変更・層の絞り込み・選んだ差を表示する。数字の 5 で開く。既存の 4 面は同じ部品を使う。

- 読み直しの結果から、裏の書き手が metadata だけの写しを作る。本文・設定値・会話記録を追加で読まない。許可済み文書だけ、同じ目録内の本文の SHA-256 を残す。記憶は大きさと更新日時だけ。
- 保存先は ~/.mycmux/agent_design/history/<正規化した作業フォルダの SHA-256>/<UTC 日時>-<UUID>.json。schemaVersion=1。項目は id・service・layer・displayName・path・kind・bytes・modifiedAt・documentHash。サービスは毎回読む量の内訳と合計、一覧の本数と字数、秘密の件数だけ。記憶の本文ファイルも裏で metadata だけを列挙する（本文・ハッシュは無い）。読めない記憶の場所は memoryUnavailable に残し、消えたことにはしない。
- 同じフォルダに 60 個、すべての履歴に合計 20 MiB まで。原子的に書き、履歴自身の古い JSON から減らす。リンク・リパースポイントへの書き込みは拒否する。壊れた写しは警告し、元の設定を開いて補わない。
- 続く写しを比較して「ファイルが変わった」と「読む量が変わった」を別の札にする。最初の写しだけでは変更を作らない。差が無い読み直しも写しを残す。
- git は項目を選ぶまで呼ばない。1 項目に git log --follow の最大 30 commit。各要求全体の上限 3 秒、出力の上限 2 MiB。外部 diff・textconv・fsmonitor・pager を止める。未知の作者は「不明」。
- commit を選んだときだけ、その項目の log に含まれる版の大きさと許された差を取得する。名前の変更の前のパスにも許可を適用する。文書は行番号つき、設定は公開してよい項目だけへ射影して差を取る。記憶・binary・台本などは「中身は出さない」。git が無い・時間切れでも写しを表示する。
- 写しには本文を残さないので、写しだけの変更は大きさと変更の事実まで。本文の差は git の変更を選んで見る。git の一覧では +/− 行数、選んだ差では前後の bytes を表示する。大きさを取得できない時は「不明」。
- API は agent_design_history / agent_design_history_git / agent_design_history_diff。既存 catalog.json・closed.json の型は変えない。書き出し（B2）・records.rs・利用者の設定の編集はこの便の範囲外。

検証は合成ホームの git と秘密・記憶の目印、Mac の Rust / tsc / Vitest、ブラウザ試験台の実データ・合成データ、公開検査で行う。ネイティブ IPC の検収と配信は別の工程。
