# iPhone 連携はクラウドを挟まず PC 直結に留める

Status: accepted (2026-08-17)

スマホからの主用途を「走っているレーンの質問・承認に答えること」と定めた。答える相手のレーンは PC 上で動いているので、その瞬間 PC は必ず起きている。したがって `minorun365/html-share` が備える「PC が寝ていても依頼を置ける」非同期クラウド層は、この主用途には要らない。クラウドを持たない分、AWS 構築・ドメイン・証明書の運用が不要になり、セッション名やレポート本文が外部へ出ない。

代償として、PC を閉じて外出している間はスマホから何もできない。「思いついた依頼を置いておき、帰宅した PC が拾う」用途が欲しくなった時点で、この判断を見直すか、html-share を併用して埋める。

## 検討した選択肢

- **html-share を併用する**: 依頼箱と静的な閲覧面をすぐ得られ、HTML レポートもスマホで読めるようになる。却下理由は、主用途が承認である以上クラウド層の主目的が空振りになり、スマホ側の入口が2つに割れるため。
- **最初からクラウド一体で設計する**: 承認と依頼が同じ入口にまとまる。却下理由は、構築・費用・秘密の取り扱いが一気に重くなり、主用途に対して釣り合わないため。
