# 日本語の語彙は「ワークスペース > タブ > ペイン」で、英語はその鏡像のまま据え置く

Status: accepted (2026-09-16・宮崎さん裁定)

日本語の画面文言・文書・報告は **ワークスペース > タブ > ペイン** で書く。
**ペインの集合がタブ**、タブの集合がワークスペースである。
コード・保存データ・ソケット API・コマンドラインの英語は、この**鏡像のまま据え置く**
(英語 `pane` = 日本語のタブ、英語 `tab` = 日本語のペイン)。改名はしない。

2026-08-11 のモックで承認し、2026-09-13 配信の v0.71.0 の更新情報
(`CHANGELOG.md` の該当節) で利用者にも公開した。内部の決めごとではなく配信済みの公約である。

## 語の定義

| 語 | 指すもの | 画面での見え方 | できること | コード・API の英語 |
|---|---|---|---|---|
| ワークスペース | 案件や調査ごとの作業のまとまり | サイドバーの 1 行 | 作成・色・キャラ・閉じる | `Workspace` / `workspace` |
| タブ | 画面を割った区画 1 つ。ペインを束ねる | 枠と、その上に並ぶ「つまみ」の列 | 分割・最大化・上下左右へ移動・統合・区画ごと切り離し | `Pane` / `pane` / `panes` / `move` |
| ペイン | セッション 1 つ (ターミナル・Web・ブラウザ・ランチャー) | つまみ 1 個とその中身 | 開く・閉じる・名前・固定・spawn・送信・読取・引き継ぎ・自動命名・掃除・再配置・窓へ切り離し | `PaneTab` / `tab` / `tabs` / `spawn-tab` / `close-tab` |

Chrome にたとえると、ワークスペースがウィンドウ、タブがタブグループ、ペインが 1 枚のタブ。
「つまみ」は、ペイン 1 個を選ぶために区画の上端に並ぶ小さな見出しを指す。

## 検討した選択肢

- **英語も日本語に合わせて反転する案は採らない。** `Pane` と `PaneTab` の改名、
  `data.json` の `panes` / `tabs` の移行、ソケット API とコマンドラインの互換期間、
  エージェント側のスキルとポケット mycmux の API の追従が同時に要る。
  保存済みのレイアウトの移行を誤ると起動できない版を配ることになり、
  区切りを作れる機会は 1.0 のアプリ名変更と同時しかない。効果に対して危険が大きい。
- **日本語を英語に合わせて「ペイン = 区画」にする案は採らない。** 2026-08-11 に承認し
  v0.71.0 で公開した定義を、公開後に裏返すことになる。
- **どちらも決めずに置く案は採らない。** 2026-08-11 から 2026-09-15 までがその状態で、
  逆向きの記載が 1,483 行たまった。

## 別義 (矛盾として数えない)

設定画面のタブ / ブラウザのタブとタブグループ / ダッシュボードの「2 ペイン・3 ペイン」構成
(画面のパネルの意味) / Web ペインの中の子 WebView が持つタブ / ポケット mycmux の「トーク」
(区画に対応) / 「スタブ」のような部分一致。

ダッシュボードのパネルは今後「パネル」と書けば衝突が消える。

## 記録は直さない

過去の記録は、そのときの画面の呼び方を書いたものである。直すと記録としての正しさが失われるので、
次のものは 2026-09-16 の掃除の対象外とした。

- `CHANGELOG.md` (版ごとの記録。v0.71.0 より前の版に逆向きの語が残る)
- `docs/plans/**` (過去の計画書)
- Claude の記憶のうち、案件の進行と調べた事実を書いたもの (索引とやり方の指示は直した)
- `skills/miyazaki-clone/store/**` (宮崎さんの過去の判断を一語一句そのまま写した資料)
- `.bak` と紹介サイトの `.build/**`

**2026-09-13 以前の記録には鏡像の語彙が混じる。** 読むときはこの ADR を基準にする。

## 結果

- 日本語を書くときは英語の識別子から訳さず、上の定義を当てる。
  英語名をそのまま片仮名にした語 (可視タブ・裏タブ・ターミナルタブ・Web タブ・無名タブ・
  タブ掃除・タブ再配置・タブ名) はすべてペインが正しく、区画を「ペイン」と書く語
  (ペインを分割・ペインを最大化・ペインを統合・左右上下のペイン) はタブが正しい。
- 用語を述べる場所はこの ADR を正とする。リポジトリルートの `CONTEXT.md` と `CLAUDE.md` は
  短い版を置いてここを指す。
- コマンドラインの `--help` は、英語が鏡像であることを 1 行で示す。
- 再発防止は `tests/unit/vocabularyContract.test.ts` が複合語だけを止める。
  地の文は機械で判定できないので、実測で矛盾の 29% しか捕まえられない。
  番人の役目は「一度直した複合語が戻ってこないこと」に限る。

2026-09-16 の掃除の判定表 (「タブ」か「ペイン」を含む 2,533 行を 1 行ずつ判定したもの) は
`reports/_quick/2026-09/mycmux_語彙棚卸し_証拠_20260915` にある。
