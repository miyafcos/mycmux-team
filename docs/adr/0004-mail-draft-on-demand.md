# 「メール」機能の返信下書きはカードからの依頼で起草する (全自動にしない)

未返信メールの監視 bot は LLM ゼロの決定的走査であり、下書き起草は Claude セッション側の仕事と分離している。元要望は「開いたときに下書きがいい感じに入っていて、Gmail では送るだけ」だったが、新着未返信を検出するたびに全自動で起草すると、返信不要なメールにも下書きが作られて Gmail の下書きフォルダが散らかり、LLM が常時稼働して RAM 逼迫 PC とコストを圧迫する。そこで起草は AttentionCards の「下書き作成」操作を起点とし、依頼された件だけを起草して Gmail の該当スレッドに下書きとして投入する (2026-08-26 宮崎さん裁定)。

**検討した選択肢**: 全自動起草 (却下: 不要下書きの散乱・常時 LLM) / 至急・VIP だけ自動で他は依頼 (却下: 2系統の挙動と自動分の取り消し導線が必要になり運用が複雑)

**結果**: 「送るだけ」になるのは依頼した件からで、ワンクリックと待ち時間が発生する。将来、依頼の粒度を「至急だけ自動」へ緩める余地は残すが、その場合は本 ADR を supersede する。
