# 下書き起草は mycmux が起動する単発ヘッドレス Claude ジョブで行う (チャット経由にしない)

カードの「下書き作成」は、mycmux が裏で単発の Claude ジョブを起動し、台帳に格納済みのスレッド全文とメール規範 (client-mail-standards / check_mail.py) を渡して起草させ、gws で Gmail の該当スレッドに下書き投入して完了する (2026-08-26 宮崎さん裁定)。ワンクリックで完結し、稼働中のチャットセッションへの割り込みもセッション有無への依存も発生しないことを優先した。文面に不満がある場合の修正は Gmail 上での手直しか再依頼で行い、対話での詰めが必要な難しいメールは最初からチャットに依頼する使い分けとする。

**検討した選択肢**: 稼働中チャットへ依頼を注入 (却下: 作業割り込み・セッション不在時に動かない) / 起草キューに積んで一括 (却下: 即時性がなく2ステップ)
